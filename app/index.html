ChemBuilder help

Getting started

  1. Draw with the editor's tools, or paste a SMILES string or MOL block straight onto the canvas.
  2. Properties update on the right as you draw. Add a reaction arrow and the Reaction tab fills in with components, atom balance and stoichiometry.
  3. Name the drawing in the top bar and press Save. It appears in the library on the left and is stored as plain files in the drawings folder.
  4. Click a library entry to open it. Use the Formats tab for SMILES, MOL, SDF, RXN, CML and InChI, and the Image tab for PNG and SVG.
